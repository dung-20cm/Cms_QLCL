Bộ công cụ này dùng để làm gì?
Đánh giá thực hành 5S tại từng vị trí trong khoa/phòng theo đúng bảng kiểm của Bệnh viện Đa khoa Thái Bình. Không cần in giấy, không cần mạng internet — chỉ cần mở file HTML này trên bất kỳ trình duyệt nào (Chrome, Edge, Firefox).

Tab Bảng kiểm:
1. Chọn khoa/phòng và điền vị trí đánh giá
2. Bấm ✓ (Đạt) hoặc ✗ (Không đạt) cho từng tiêu chí
3. Kết quả và xếp loại hiển thị tự động — bấm Lưu kết quả để ghi vào bộ nhớ

Tab Tổng hợp:
Xem tất cả lượt đã đánh giá. Bấm Xuất CSV để tải về file Excel — gửi về phòng QLCL hoặc đẩy lên Google Sheets.

Tab Xu hướng:
So sánh tỷ lệ đạt từng S giữa các lượt, xác định điểm mạnh và điểm cần cải thiện.

Lưu ý:
Dữ liệu được lưu trong bộ nhớ trình duyệt (localStorage). Nếu xoá cache trình duyệt, dữ liệu sẽ mất — hãy Xuất CSV thường xuyên để sao lưu.
Nên dùng file HTML này trên 1 máy tính cố định của phòng QLCL hoặc mạng lưới QLCL.

Thang đánh giá:
✓ Đạt tốt ≥ 85% tiêu chí đạt  |  ◎ Đạt ≥ 70%  |  △ Chưa đạt ≥ 60%  |  ✗ Không đạt < 60%

⚙️ Kết nối Google Sheets
Đồng bộ dữ liệu từ nhiều máy về một Google Sheet chung
📡 Trạng thái kết nối
Chưa cấu hình. Nhập URL Apps Script bên dưới để bắt đầu.
🔗 URL Web App (Apps Script)
🔄 Đồng bộ dữ liệu
⬆️ Đẩy dữ liệu local lên Sheet
Bấm để đẩy toàn bộ dữ liệu đang lưu trên trình duyệt này lên Sheet. Dữ liệu sẽ được ghi đè nếu đã tồn tại.
⬇️ Kéo dữ liệu từ Sheet về máy
Ghi đè dữ liệu local bằng dữ liệu mới nhất trên Sheet (dùng khi dùng nhiều máy).
📋 Hướng dẫn thiết lập (5 bước)
  1. Mở Google Sheets → tạo một Spreadsheet mới → đặt tên "5S_BVTB"
  2. Vào menu Extensions → Apps Script
  3. Xoá code mặc định → paste toàn bộ nội dung file 5S_AppScript.gs vào
  4. Bấm Deploy → New deployment:
      • Type: Web app
      • Execute as: Me
      • Who has access: Anyone
      → Bấm Deploy → Copy URL hiện ra
  5. Dán URL vào ô trên → Bấm Lưu & Kiểm tra kết nối
💡 Sau khi kết nối: mỗi lần ai bấm "Lưu kết quả" hoặc "Lưu" hành động KP, dữ liệu tự đẩy lên Sheet ngay lập tức. Sheet sẽ có 2 tab: KetQua_5S và HanhDongKP.
👥 Quản lý tài khoản
Chỉ admin mới thấy mục này. Thay đổi mật khẩu có hiệu lực ngay trên máy này và đồng bộ lên Sheet khi bấm "Đẩy lên".
